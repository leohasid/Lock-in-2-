Vercel Environment Variable

Click the button to copy the variable name:

NEXT_PUBLIC_RAILWAY_API_URL
How to use:
  1. Click "Copy" above
  2. Go to Vercel → Your Project → Settings → Environment Variables
  3. Click "Add New"
  4. Paste the variable name in the "Name" field
  5. Add your Railway URL in the "Value" field
  6. Select all environments and Save
